## 🌟 Key Features
- **Careem-Inspired Design:** Clean, modern, international aesthetic with black, gold, and subtle crimson branding.
- **100% AI-Generated Assets:** Custom photorealistic fleet imagery (Swift Dzire, Ertiga, Innova Crysta, Scorpio, Tempo Traveller, luxury buses, highway sunset hero banner).
- **Interactive Booking Form:** Instant trip calculation with pickup, drop, trip type (One Way / Round Trip / Local), vehicle selection, and date/time.
- **Dynamic WhatsApp Integration:** Automated pre-filled WhatsApp messages for cabs, buses, Tempo Travellers, tour packages, and custom inquiries (`+91 85308 47555`).
- **Full Fleet Showcase:** 11 detailed vehicles with capacities, luggage space, and A/C guarantees.
- **20 Specialized Travel Services:** Pune-Mumbai daily express, airport transfers, outstation cabs, wedding fleets, corporate mobility, hotel and resort stays.
- **Popular Destinations Gallery:** Lonavala, Mahabaleshwar, Shirdi, Mumbai, Goa, Lavasa, Alibaug, and Ashtavinayak Darshan.
- **Mobile First & Ultra-Fast:** Fully responsive across all mobile viewports (320px–430px) and desktops.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for production
```bash
npm run build
npm start
```
